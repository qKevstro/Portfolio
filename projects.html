HTML Event Website

Nordisk Pixel Gaming 2027 är en event-hemsida skapad med ren, semantisk HTML5. Sidan informerar besökare om ett nordiskt spel-event med e-sportturneringar, brädspel, komedishow och fotbollsmatcher. Projektet innehåller strukturerade informationsektioner, ett interaktivt anmälningsformulär med input-fält samt en schematabell över dagens aktivitetstider och kontaktuppgifter.

RGB Keyboard Project

This project is an interactive, browser-based "Dynamic RGB Keyboard" created using HTML, CSS, and JavaScript. I designed a customized mechanical keyboard layout from scratch using precise CSS layouts and styling. Using JavaScript, I simulated dynamic per-key RGB backlighting and created a hidden logic-based puzzle. This project demonstrates my abilities in front-end design, advanced CSS positioning, and DOM manipulation to create engaging, fun interactive elements.

Online Video Game Shopping Site

This project is an online video game shopping site created using HTML, CSS, and JavaScript. The site features a user-friendly interface where visitors can browse and purchase video games. It includes product listings, a shopping cart, and a checkout process. The project demonstrates my ability to create functional e-commerce websites with interactive elements and responsive design.
